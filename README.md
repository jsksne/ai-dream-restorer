# AI 梦境还原器（无限探索版）

> 模仿 flipbook（翻页画册）的**无限向内探索**机制：从一张梦境图像出发，点击画面中的任意元素，不断生成下一层、再下一层，所有旧分支都不会丢失。

本项目核心流程是 **生成图像 → 探索 → 生成分析** 的循环：先还原一段梦境，再像翻阅画册一样一层层深入画面细节，最终选中"最接近记忆"的版本，生成一份非诊断性的心理报告。

## 快速上手

```bash
npm install
npm run dev
# 打开 http://localhost:3000
```

首次进入会弹出引导弹窗，选择 **AI 辅助生成**（提示词教练通过少量追问帮你补齐画面）或 **自己生成**（全程自己描述），随后按提示操作即可。

## 核心流程

1. **生成图像**：在底部输入框描述梦境，AI 会先优化/追问，确认后生成初始画面。
2. **探索（无限分支）**：单击画面中的元素，AI 识别该区域并生成"子梦境"（镜头下潜/空间深入）。可沿面包屑回到任意旧节点再次分叉，所有分支保留，形成一棵无限生长的探索树。
3. **生成分析（心理报告）**：把最接近记忆的版本标记为"最像"，点击 **读读这个梦**，AI 基于画面证据与梦境描述生成四段非诊断性内容（梦境线索、情绪脉络、可能的现实联想、可供思考的问题）。

## 右上角工具栏

| 按钮 | 作用 |
|---|---|
| `?` | 新手引导说明：点击后先显示欢迎弹窗，再选择「AI 辅助生成 / 自己生成」 |
| `档` | 梦境档案馆：读取本地保存的梦境存档，可新建、继续、重命名、导出、导入 |
| `我` | 设置自己的信息（Dream Self）：创建梦中"我"的形象档案，让同一人物在多次生成中保持身份连续性 |

## 技术架构

```
UI (React 19 + Zustand + GSAP + Tailwind CSS 4)
  ├── IndexedDB（项目/档案/设置/草稿持久化）
  ├── useOperation（operationId + sequence 客户端任务隔离）
  └── /api/* → Orchestrator（A2A 风格编排） → Provider (live|mock|demo)
                                                  │
                                                  ▼
                                          受控资产仓库
                                          .oneira-data/assets/（UUID 资产 ID）
```

- **无限分支树**：节点字典 + 父/子引用，旧分支不因新探索而丢失
- **真实阶段进度**：理解梦境 → 组织场景 → 生成图像 → 保存并识别，取消即时生效，不伪造百分比
- **受控资产仓库**：图片只通过不可猜测的 UUID 资产 ID 访问，拒绝任意本地路径（防路径穿越）
- **统一任务生命周期**：operationId + 递增序号，旧操作的结果/错误不会污染新会话
- **真正的多模态分析**：VLM 先抽取图片中的可观察证据，文字模型再基于证据合成内容
- **零额度测试**：Mock Provider 可在无 API Key 时跑通全部测试

## 已知问题（欢迎协助修复）

以下是目前已知的、尚未完全解决的 Bug，按影响排序：

1. **VLM 语义标签经常降级为"未知"**：图像生成成功后，场景/情绪标签常显示为"未知"、元素列表为空（`lib/agents/dream-generator.ts` 中 VLM 调用失败时降级为默认值）。这会导致元素 hover 高亮和语义标签展示失效。怀疑与视觉模型请求格式或模型可用性有关。

2. **提示词教练偶发返回截断的 JSON**：AI 辅助模式下，提示词教练的回答偶发被截断导致解析失败（已加内置追问降级，体验尚可但非最优）。可能与模型 `max_tokens` 或输出稳定性有关。

3. **探索时的元素识别会降级为"画面中心"**：点击画面元素时，若视觉识别失败会退回"画面中心"标签（`runElementIdentify` 的 catch 降级），导致探索方向可能与用户点击位置不符。

4. **心理分析入口较隐晦**：必须先「保存为版本」→「这张最像！」选中版本后，「读读这个梦」按钮才可用。不熟悉流程的用户容易找不到分析入口。

5. **长时间连续操作后建议刷新页面**：多次连续生成/探索后，浏览器与服务端的 SSE/连接资源可能累积，偶尔出现后续请求变慢，刷新页面可恢复。

6. **引导弹窗每次刷新都会弹出**：为方便演示，Onboarding 弹窗每次进入页面都会显示（模式选择会记住），若觉得打扰可改为只显示一次。

## 安全与隐私

- API 密钥只在服务端环境变量中读取，不写入代码、文档或测试夹具
- 所有图片通过 `/api/assets/{assetId}` 受控访问
- 心理分析为非诊断性自我探索内容，不含医学结论
